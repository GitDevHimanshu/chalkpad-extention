"# chalkpad-extention" 
## Installation

### Step 2: Open the Extensions Page

Open your browser and type the following in the address bar:

**Google Chrome**

```
chrome://extensions
```

**Microsoft Edge**

```
edge://extensions
```

---

### Step 3: Enable Developer Mode

Turn on the **Developer mode** toggle in the top-right corner of the page.

---

### Step 4: Load the Extension

1. Click **Load unpacked**.
2. Select the **chalkpad-extension** folder (the folder containing the `manifest.json` file).
3. Click **Select Folder**.

The extension will be installed and appear in your browser.

---

### Step 5: Reload After Changes

Whenever you make changes to the extension:

1. Open the Extensions page.
2. Click the **Reload** (⟳) button on the **ChalkPad Extension** card.
3. Refresh the webpage to see the updated changes.
